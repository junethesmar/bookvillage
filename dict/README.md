# 영어 표현 도감 (dict)

- `index.html`: 구글 드라이브 `english-dict/index.html`을 그대로 옮긴 것. 책갈피 마을 공부방 「📗 표현 도감」에서 열려요.
  주소: https://junethesmar.github.io/bookvillage/dict/
- 도감을 고치면 드라이브에서 작업한 뒤 이 파일만 덮어쓰면 돼요.
- `audio/` 폴더(문장별 mp3)를 이 폴더 안에 올리면 녹음된 목소리로 읽어요. 없으면 기기 음성으로 읽어요.
  올리는 법: GitHub 저장소 → `dict` 폴더 → Add file → Upload files → 드라이브의 `audio` 폴더를 통째로 끌어다 놓기
