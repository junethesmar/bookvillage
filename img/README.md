# 마을 그림

이 폴더에는 **아이소메트릭 미니어처(디오라마) 화풍의 기본 그림이 들어 있어요**(384px 투명 PNG 44장 + 마을 바닥판 `village_bg.png` + 입장 화면 그림 `hero.jpg`, 모두 합쳐 약 2MB).
마음에 안 드는 그림만 **같은 파일 이름**으로 덮어쓰면 바뀌어요. 파일을 지우면 그 물건은 이모지로 보여요.
아래는 ChatGPT로 직접 다시 그리고 싶을 때 쓰는 안내예요.
들어간 그림은 교사 화면 → 「🏡 마을 놀이」 → 「마을 그림 점검」에서 초록색으로 보여요.

## 1. ChatGPT에 처음 한 번 보낼 말 (그림체 맞추기)

한 대화창에서 계속 만들어야 그림체가 맞아요.

```
초등학생용 독서 앱에 들어갈 아이템 그림을 여러 장 만들 거야. 앞으로 모든 그림은 이 규칙을 지켜 줘.
- 아이소메트릭 미니어처(디오라마) 스타일: 점토·플라스틱 장난감 미니어처 같은 귀여운 3D 렌더, 따뜻한 파스텔톤, 둥근 모서리, 부드러운 조명
- 물건 하나만 가운데에, 정확한 아이소메트릭 각도(30도)로 비스듬히 내려다본 시점
- 마을 집·시설은 작은 네모 잔디 받침 위에 올려 주기
- 벽에 거는 물건(전구·시계·창문·액자·별 무드등)은 왼쪽 벽에 붙은 방향으로 (오른쪽 벽에 걸면 앱이 저절로 뒤집어요)
- 배경은 완전히 투명한 PNG (흰 배경 X, 그림자 바닥 X)
- 글자 넣지 않기, 정사각형 1024x1024
준비되면 "좋아"라고만 대답해.
```

그다음에는 `침대 그려줘`처럼 한 줄씩 보내고, 받은 그림을 **아래 파일 이름으로 바꿔서** 저장하세요.

> ⚠️ 배경이 하얗게 나오면 벽지 위에 흰 네모가 생겨요. 그럴 때는 "배경 투명하게 다시"라고 해 주세요.

## 3. 올리는 방법

- **GitHub 웹에서**: 저장소 → `img` 폴더 → `Add file` → `Upload files`로 올리면 돼요.
- ChatGPT 그림은 한 장에 1~2MB라서 40장을 그대로 올리면 학교 와이파이에서 느릴 수 있어요.
  올린 뒤 Claude에게 "그림 줄여줘"라고 하면 작은 크기로 줄여서 다시 올려 줄게요.
